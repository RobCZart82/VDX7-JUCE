# GYR About mark

`1x/gyr-logo.png` is an unchanged copy of the user-supplied `GYR-Logo2.png`,
included at the project owner's explicit request for the ABOUT window.
It is a GYR identity mark, not a Yamaha asset or a newly generated logo.
The reference hardware photographs and GUI concept images are not bundled.

The white background and aspect ratio are preserved. The GUI scales it at
render time without modifying the source image. Logo/trademark ownership is
not transferred by inclusion in this repository.
