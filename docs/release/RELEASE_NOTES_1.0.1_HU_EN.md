# VDX7 Mk1. 1.0.1 / Javítókiadás

## English

VST3 corrective release for Windows x64 and macOS Universal (Apple Silicon and Intel). Choose the EXE/PKG installer or the corresponding Manual Install ZIP. AU and Standalone are not included. Original, legally obtained DX7 Mk I v1.8 firmware must be supplied by the user; Special Edition firmware is not supported. Yamaha firmware and factory banks are not included.

Includes project-state protection, SysEx compatibility corrections, automatic discovery of user-supplied factory banks by content, and the final edited-voice export correction. An edited, unsaved voice is preserved with DAW project state. Existing GUI screenshots remain unchanged.

The Windows installer is unsigned. The macOS installer is unsigned/not notarized; ad-hoc plugin signing is not Developer ID signing. Security warnings may appear. Only approve a download you trust and have checked; do not disable system-wide security protections.

Automated Windows/macOS tests, package/installer integrity, checksums and complete matching source verification passed for this exact candidate. Owner-reported host tests and macOS project recall of both selected and edited (*) voices passed. These are scoped results, not a universal compatibility guarantee. Explicitly NOT RUN / DEFERRED with owner approval: the full sample-rate/buffer and offline/real-time render matrix; detailed automation, multi-instance, HiDPI and native-dialog checks; physical Intel Mac testing; detailed old-project recovery with missing/different ROM. Earlier 1.0.0 tests are not automatically counted as 1.0.1 tests.

## Magyar

VST3 javítókiadás Windows x64 és macOS Universal (Apple Silicon és Intel) rendszerre. Az EXE/PKG telepítő vagy az adott rendszer Manual Install ZIP csomagja választható. AU és Standalone nincs mellékelve. Saját, jogszerűen használható eredeti DX7 Mk I v1.8 firmware szükséges; a Special Edition firmware nem támogatott. Yamaha firmware és gyári bank nincs a csomagban.

Projektállapot-védelem, SysEx-kompatibilitási javítások, saját gyári bankok tartalom szerinti automatikus felismerése és a módosított hangszín exportjának végső javítása. A módosított, külön el nem mentett hangszínt a DAW projektállapota megőrzi. A korábbi GUI-képek változatlanok.

A Windows telepítő nincs aláírva. A macOS telepítő nincs aláírva/notarizálva; a plugin ad-hoc aláírása nem Developer ID aláírás. Biztonsági figyelmeztetés megjelenhet. Csak megbízható, ellenőrzött letöltést engedélyezz; ne kapcsold ki a rendszer egészének védelmét.

Az ehhez a pontos csomaghoz tartozó automatizált Windows/macOS tesztek, telepítő- és csomagellenőrzések, ellenőrzőösszegek és teljes megfelelő forrás ellenőrzése sikeres. A tulajdonos host-próbái és a macOS projekt-visszatöltés kiválasztott, illetve módosított (*) hangszínnel sikeresek. Ez nem általános kompatibilitási garancia. Jóváhagyással NEM FUTTATOTT / HALASZTOTT: teljes mintavétel/pufferméret és offline/valós idejű render mátrix; részletes automatizálás, többpéldányos működés, HiDPI és natív fájlablak; fizikai Intel Mac; régi projektek részletes helyreállítása hiányzó/eltérő ROM-mal. Az 1.0.0 tesztjei nem számítanak automatikusan 1.0.1 tesztnek.
